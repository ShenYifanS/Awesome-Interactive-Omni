# 📖 Glossary

[← Home](../README.md) · [Reading guide](reading-guide.md)

| Term | Meaning in this collection |
| --- | --- |
| Omni intelligence | Integrated perception, reasoning, knowledge and generation across modalities. |
| Interactive omni intelligence | Exercising those capabilities while input, output and interaction state continue to evolve. |
| Real-time interaction requirements | The observable requirements governing input arrival, state updates and when output may start, change or stop (earlier drafts called this the interaction contract). |
| Native interaction | Temporal structure and interaction control represented and learned within the model. |
| Adapted system | A pretrained model extended with modality modules, interfaces, post-training or orchestration for interaction. |
| Full duplex | Listening and speaking can overlap. |
| Half duplex | Listening and speaking alternate rather than occurring simultaneously. |
| Backchannel | A brief listener signal such as “mm-hm” that need not take the conversational floor. |
| Barge-in | User input arriving while the system is speaking; it may require stopping, revising or continuing. |
| Endpointing | Deciding that a user's input segment or turn has ended. |
| Semantic repair | Updating the interpretation, response and task state after a correction or misunderstanding. |
| Proactivity | Initiating a response or action when the evolving situation warrants it, without requiring a completed explicit request. |
| Addressee recognition | Determining whether speech or another signal is directed to the assistant. |
| Thinker–Talker | An architectural separation between multimodal/language processing and spoken generation. |
| Foreground–background | A coordination pattern combining immediate interaction with slower, often asynchronous computation. |
| Multi-rate intelligence | Coordinating processes with different update rates, latency requirements and commitment levels. |
| Provisional output | Output or an internal result that may still be revised before it becomes a durable commitment. |
| Committed / heard output | Output whose effects or playback must be reflected in the current interaction state. |
| Stale result | A returned result that was valid for an earlier request or state but may no longer be relevant. |
| Time-to-informative-answer | Delay until task-relevant information reaches the user, distinct from the first acknowledgment or audio sample. |
| Capability preservation | Retaining reasoning, knowledge and grounding when introducing speech, modalities or interactive behavior. |
| Intelligence–interactivity trade-off | Training and runtime tensions between preserving capability and satisfying temporal interaction demands. |
